# obsidian-glass-tokens

Dark-first **Obsidian Glass** CSS custom-property token package (`#08080b` canvas, `#101015` raised, `#5E4AE3` violet accent, `#A99BFF` link accent, `#FF7A1A` ember status) with an opt-in `[data-theme="light"]` palette.

## Installation

```bash
npm install obsidian-glass-tokens
```

Import in your global CSS or Astro layout:

```css
@import "obsidian-glass-tokens/tokens.css";
```
